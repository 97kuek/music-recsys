## 未聴正解対象

| 条件 | 正解を持つユーザー | ユニーク正解ペア |
| --- | ---: | ---: |
| validation / train学習 | 23,914 | 2,874,931 |
| test / train学習 | 17,401 | 2,397,254 |
| test / train+validation再学習 | 17,692 | 3,037,889 |

- 学習で観測したユーザー・曲をWarmとする。
- 期間の開始時点で1回推薦し、その後の期間に聴いた未聴曲を正解候補として集計。
- testでは、どちらの学習条件でもvalidation中に聴いた曲を既聴として除外。
- 関連度は1回以上再生したユニークペアとして仮集計。学習方式によって対象集合が異なり、人数差は性能差ではない。
- 除外理由と履歴1 / 5 / 10 / 20曲以上の対象数は集計JSONに保存。
